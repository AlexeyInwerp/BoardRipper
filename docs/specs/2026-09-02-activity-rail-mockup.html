What changes — hover to locate

Notes on the build

state

The rail needs no new state. It reads the same activeTab / collapsed / side module state in Sidebar.utils.ts, through exports that already exist — showSidebarTab, toggleSidebar, flipSidebarSide.

gesture

Click a destination to switch; click the active one to collapse. That one rule replaces all three current toggles, and the rail stays put while collapsed so the destinations never disappear — only the indicator goes grey.

captions

Switch Captions to Icons only above to judge the tradeoff yourself. Icon-only saves 4px per item and looks tighter; the hover label is the safety net either way. My read: keep captions until the rail is muscle memory.

badges

Wired to state that exists today — updateStore, librarysync errors, the log store's error count. This is the one thing a horizontal tab strip structurally cannot give you. The toolbar version chip stays; it names the build, which is not a destination.

open

BoardSidebar is untouched here. Its five tabs are a second, board-local sidebar on the canvas's right edge. A secondary rail is the obvious sequel — deliberately not in this step.

open

Where does 2-window mode go? It is a layout control sitting in the Files group. If the rail becomes the layout surface, that button has a better home than beside Upload.
